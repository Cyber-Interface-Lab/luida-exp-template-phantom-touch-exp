要約

LUIDA 本体には手を入れず、GUI で組める部分は GUI で組みます。Cluster Script を書くのは 4 箇所だけです。

実装方針

変数・ステート・質問紙・Data Collector・アバター登録は GUI。スクリプトは NPC、アバター切替ゲート、報告パネル、デバイスチェックのみ。

公開直前の本体改修リスクを避ける。

要因配置

参加者間 social・order をサーバ均衡割付。参加者内 block×rep で 4 試行。アバター条件は order×block から導出。

isRandom は反復をブロック化しないため。

ステート

標準の試行ループ内に Setup・Touch・Report・VEQ を置き、条件に合わない回は即スキップ。

設定量が最小で、GUI の If ゲートも使える。

NPC

既存 VRM を LUIDA でラッパー化し、自作スクリプトで 2 ボーン IK のリーチと注視を動かす。

アイテムには HumanoidAnimation を適用できない。

自己アバター

参加者自身が着替え、骨の長さで自動判定し、ボタン＋二段階確認で開始。1 ワールド内で完結し、ポータルは不要。

ご指定の手順に、取り違え検出を加えた。

データ

1 試行 1 行で蓄積し、End で 1 回だけアップロード。ルームログは補完。

サーバは同名ファイルを上書きするため。

自己アバター条件の操作

入室時は透明アバターです。Web Console の参加者アバターモードを HIDE にすると、管理ボットが「入室時に透明アバター、自分のアバターへの切替は許可」と設定します（反映は翌日）。

  1. 指示：普段使い条件なら「普段いちばん使うアバターに」、割当条件なら「最初に着ていた透明アバターに」着替えるよう表示します。
  2. 自動判定：腕の長さと肩幅で透明アバターかどうかを毎フレーム判定し、目標と一致したときだけ「着替えました」ボタンを出します。
  3. 一段階目：「着替えました」を押します。
  4. 二段階目：「いま着ているのは普段最もよく使うアバターですか？」などに「はい／いいえ」で答えます。「いいえ」なら手順 1 に戻ります。
  5. 記録して開始：腕長・肩幅・頭の高さ・切替にかかった時間を保存し、試行へ進みます。
// 透明アバター（transparent-avatar.vrm）の実測値。実機で更新する

// 腕長と肩幅がどちらも許容差内なら透明アバター（1 秒連続で採用）
確認済み（2026-10-23）入室時に割り当てられた透明アバターは、参加者が一覧から再び選べます。

ポータルは不要

Study 2 では Cluster が入室時にしかアバターを割り当てないため、条件ごとに別ワールドを作りポータルで移動させていました。本案では参加者が同じワールド内で着替えるので、2 つのアバター条件を 1 ワールド・1 インスタンスで実施できます。ワールド移動による脱落（Study 2 では 9.2%）も起きません。

残るゲートは、終了後に募集ワールドへ戻る WorldGateToLuidaBar と、不適格者を送り出す既存の仕組みだけです。

NPC（社会的手がかり）

作り方

  1. 既存の YoungAvatar.vrm を LUIDA の Configure avatars に登録し、生成されたラッパーと骨マップを複製します。
  2. 同期スクリプトを外し、自作の NpcController.js を載せます。
  3. CCK の Global Logic で、NPC の完了シグナル npc_done をグローバルへ中継します。

腕のリーチ軌道は両条件で同一です。差は手がかりだけになります。

試行内報告パネル

試行ごとの報告は質問紙ではなく、自作のボタンパネルで取ります。評定 0 のときに後の質問を飛ばせることと、NPC の計測値と同じ行に保存できることが理由です。

  1. 顔に何か感じたか（0–10）
  2. NPC が自分に注意を向けていたか（1–7）
  3. 評定が 1 以上なら、感覚の種類（複数選択）
  4. 評定が 1 以上なら、感じた部位（複数選択）
  5. 保存して次へ

B. 2 ボーン IK（肘位置の計算） 
function solveElbow(S, T, L1, L2, bendHint) {
  const toT = T.clone().sub(S); let d = toT.length();
  d = Math.max(0.01, Math.min(L1 + L2 - 0.001, d));
  const dir = toT.normalize();
  const cosS = (L1*L1 + d*d - L2*L2) / (2*L1*d);
  const angS = Math.acos(Math.max(-1, Math.min(1, cosS)));
  const n = dir.clone().cross(bendHint).normalize();
  const q = new Quaternion().setFromAxisAngle(n, angS * 180 / Math.PI);
  return S.clone().add(dir.clone().applyQuaternion(q).multiplyScalar(L1));
}
